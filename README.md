# Intelligence System

Two intelligent-system assignments built end-to-end: raw tabular data → trained ML models → a full-stack demo app. Each assignment trains and compares 6 classical ML models, picks the best one by held-out performance, and serves it through a React frontend + Node.js backend with a Python inference worker.

## Structure

```
Assignment_1_Diabetes/            Binary classification — diabetes risk screening
├── notebook/                     Report.ipynb, Report.pdf, dataset
├── report/                       Written report (Report.md, images/, compiled PDF)
└── app/                          Demo app (frontend + backend)

Assignment_2_Predict_Housing_Price/   Regression — Vietnam property price estimation
├── notebook/                     Report.ipynb, dataset
└── app/                          Demo app (frontend + backend)
```

Each `app/` is a self-contained full-stack project: a Vite/React/TypeScript frontend and an Express backend that spawns a Python worker (scikit-learn/XGBoost/SHAP) for inference.

## Assignment 1 — Diabetes Risk Screening

Predicts whether a patient is diabetic from 8 clinical measurements (Pima Indians Diabetes dataset, 768 records).

| Model | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|
| **XGBoost** (selected) | 87.66% | 0.818 | 0.833 | **0.826** |

Model is selected automatically by highest F1 on the test set. The app shows a risk score, per-model breakdown, and SHAP-based feature explanations.

## Assignment 2 — Housing Price Estimation

Predicts residential property price (billions VND) from listing attributes (Vietnam housing dataset, ~30k listings).

| Model | R² | MAE (tỷ) | MAPE |
|---|---|---|---|
| **XGBoost** (selected) | 0.527 | 1.163 | 23.8% |
| SVR (RBF) | 0.526 | 1.119 | 22.4% |
| Random Forest | 0.485 | 1.204 | 24.6% |

The app shows a price estimate with range, price/m², district comparison, SHAP explanations, and comparable listings from the training data.

## Running a demo app

Each `app/` needs a Python environment (scikit-learn, xgboost, shap — see `app/backend/requirements.txt`) and Node.js.

```bash
# backend
cd Assignment_X.../app/backend
pip install -r requirements.txt
npm install
node server.js          # http://localhost:8001

# frontend
cd Assignment_X.../app/frontend
npm install
npm run dev              # http://localhost:5173
```

Assignment 2's backend model artifacts are generated by running `train_all.py` in `app/backend/` (trains all 6 models, saves `.pkl` files + metrics).

## Notebooks

Each `notebook/Report.ipynb` contains the full pipeline: EDA, preprocessing, model training with cross-validated hyperparameter search, evaluation, and a representation-analysis experiment — runnable top to bottom.
